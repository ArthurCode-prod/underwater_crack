# Code and Data Availability Statement

The implementation, pretrained model, dataset split, and tabular results supporting this study are publicly available at:

https://github.com/ArthurCode-prod/underwater_crack

The released dataset contains the crack images and binary labels used in the experiments. The underwater appearances used in the manuscript are generated from these crack images by the provided synthetic degradation module; they should therefore be interpreted as simulated underwater degradation samples rather than real underwater field acquisitions.
